# My Microservices Project
Le microservice feedback-microservice gère les retours d'expérience des utilisateurs sur les formations.
Il permet d'ajouter, de consulter, de filtrer, de mettre à jour et de supprimer des feedbacks. Il est intégré dans un écosystème de microservices avec :

## Microservices inclus
- api-gateway
- eureka-server
- feedback-microservice
  
## Fonctionnalités principales
- Ajouter un feedback

- Récupérer tous les feedbacks

- Supprimer un feedback

- Mettre à jour un feedback existant

- Filtrer les feedbacks par note (rating)

- Obtenir la note moyenne d’une formation

- Compter le nombre de feedbacks pour une formation
## Technologies
- Spring Boot
- Spring Cloud
- Spring Cloud Gateway
- Eureka Discovery
